# layer-charly-internals

The `charly-internals` candy of [opencharly/charly](https://github.com/opencharly/charly), as a
standalone repo (the candy de-submodule cutover, kind-prefixed naming).

It is a concept candy: it ships no install content, and owns the `charly-internals` family's
`skill:` entities. The published skills are generated from this manifest into
[opencharly/marketplace](https://github.com/opencharly/marketplace) — edit the `skill:` entities
here, never the generated `SKILL.md`.
