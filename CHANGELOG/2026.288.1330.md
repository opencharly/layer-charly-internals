# 2026.288.1330 — docs(skill)!: every check must be derived from the artefact, in its own terms

## Summary

Adds a second reference subsection to the `git-workflow` skill's `evidence-and-freshness.md`:
**"Every check must be derived from the artefact, in the artefact's own terms"** — the twelve check
failures of one session reduced to the single rule they share.

Each entry is a real failure with its remedy: a count that named the wrong object; a truncated hash
presented as identity; the digest of an empty stream; a rule answered from memory about a file whose
`jobs:` block was never read; a diff read only where the author meant to change something; a display
formatter applied to data later parsed; the instance fixed while the class survived; a sweep for
expected words rather than the claim; a line-shaped grep defeated by a wrapped sentence; a UTC
timestamp read as local; a process count mistaken for a process tree; and a blanket regex that rewrote
a commit's TREE into its own HEAD.

The measured cost of not having the rule is in the text: five review rounds on one PR, twenty-five PRs
carrying one template's defects, and an hour of reporting "waiting on machinery" while the machinery had
already answered.

Closes #121
