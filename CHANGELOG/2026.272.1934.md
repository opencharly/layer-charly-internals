# 2026.272.1934 — docs(agents-skill)!: the orchestrator owns the entire PR surface; subagents research/write/merge code only

## Summary

Corrects the **`agents` skill's responsibility matrix** (the source behind
`/charly-internals:agents`) to match the corrected `AGENTS.md` contract. It previously said the
orchestrator's role and that the **Implementation teammate** owns "**authoring its PRs**" — the
hands-off model that just failed on `charly#717` (nine PRs BLOCKED and unchanged because the
orchestrator had delegated the PR surface).

**Changes (the matrix):**
- **Orchestrator — Owns:** added the **ENTIRE PR SURFACE** — creates every PR, runs every push
  (*a SINGLE push after it has fully validated the change AND the PR body itself*), reads every
  `charly/pr-validator` verdict **IN FULL**, and ensures **every finding is fixed before the
  next push** (all findings in ONE commit; never a partial fix; never a push at the block
  limit). Sub-agents may commit freely; only the orchestrator pushes.
- **Implementation teammate — Never:** creates a PR; pushes; writes a PR body; reads or
  dispositions a verdict; decides a merge; coordinates. It **commits freely** (many commits
  fine) and hands the worktree back with a precise report. (The old "authoring its PRs" and
  "fix-rounds in-place on CHANGES-REQUESTED" are deleted.)
- **Transient sub-agent — Never:** PUSHES or PRs (it may commit in its own worktree).

This is the skill half of the pair; the `AGENTS.md` half is `opencharly/opencharly#324`.
