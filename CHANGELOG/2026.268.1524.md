## How tested

The sweep is WRAP-TOLERANT (a Python regex over the whole file) because a
line-based grep cannot see a name split across a wrapped line. The pattern is
anchored so the NEW `charly task <name>` commands do not match:

```
$ python3 - <<'PY'
import re
s = open('charly.yml').read()
pat = re.compile(r'(?<!charly )\btask[\s`\n]+(verify|sync|map|harness|skills|hooks|build:binary|build:install-portable|mods:tidy|cue:gen|wire:gen|proto:gen)\b')
print([(s[:m.start()].count('\n') + 1, m.group(0)) for m in pat.finditer(s)])
PY
[(4398, 'task cue:gen')]
```

That single hit is the intentional historical mention. A separate check confirms
no `Taskfile` / `taskfiles/` survives, and the edited manifest parses:

```
$ python3 -c "import re;s=open('charly.yml').read();print(len(re.findall('Taskfile',s)),len(re.findall('taskfiles/',s)))"

$ yq -e '.' charly.yml >/dev/null
```
