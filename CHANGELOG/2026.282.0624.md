## Summary

The skills now state the HOW for the restructured umbrella `AGENTS.md` (opencharly/opencharly#446), and each rule is stated once.

- **cutover-policy — R1 "fix it or file it" replaces the thematic-batch deferral.**
  - A non-blocking finding is FILED (an existing issue gets the evidence, otherwise ONE new issue) and listed under the PR body's `## Filed issues`.
  - A finding raised ON the PR is never filed away.
  - The blocking/non-blocking discriminator and the "separable" test are no longer restated here.   - The batch law is now **sizing** only: filed issues are collected into theme-coherent PRs.
- **git-workflow, "BEFORE ANY UPDATE PUSH" — six ordered steps:**
  1. read every new comment IN FULL, paginated and tracked by comment id;
  2. read the full validator result;
  3. fix EVERY finding, or rebut it with evidence;
  4. run a fresh RCA for every validation failure, naming the missed control;
  5. answer coordination first;
  6. write the whole body, then push ONE commit.
- **git-workflow, B1** matches "Commit, push, land": local commits are free, R10 runs on the committed tree, and the first push opens a ready PR (no drafts).

  - post `BLOCKS`/`UNBLOCKS` on BOTH threads;
  - answer coordination first;
  - record every coordination thread in the ledger;
  - post `RESOLVED` at close-out.
