# 2026.270.0817 — docs(internals): when an auto-closed PR is re-attempted, comment on the old PR referencing the new one

## Summary

Adds guidance to the `git-workflow` skill for the **auto-closed-PR** case:

- **B5 detail** (`references/validator-and-calver.md`, new subsection *"If the PR is
  AUTO-CLOSED after too many failed validation rounds"*): if a PR is auto-closed after N
  consecutive BLOCK rounds (or the operator closes it) and the work is picked up again in a
  NEW PR, the author **MUST post a comment on the OLD (closed) PR that references the new
  PR** (its number/URL) and states what it supersedes. A closed PR is a durable, public
  record — a reader, or the next `pr-validator` running comment intake, must be able to
  follow the thread to where the work continued. Never silently abandon a closed PR.
- **Invariant** (the "Update the PR; never close-and-recreate" bullet) gained the same
  mandatory-reference sentence, so the rule is visible at the top-level list.
