# 2026.296.0218 — docs(internals): a relation over the change's own numbers needs its operands, and a constant needs its source named

## Summary

The `git-workflow` family's **pre-validator self-audit** owns the class-6 arm — *a property
claim about the changed surface is a CHECK*. Its **PROSE half**, landed in #134, says a
claim about the change's OWN measurements is checked against the measurements rather
than against the code. It says nothing about what such a claim must **contain** for that
check to be possible by a reader, and two shapes slipped through it. Both were measured
on the umbrella PR `opencharly/opencharly#591`:

- **A relation over the change's own numbers, stated without its operands.** #591's
  round-2 body said a bootstrapped light tree was *"still three orders of magnitude
  below the 9.5 G a full checkout occupies"*, while the two numbers the same sentence
  names are 124 M and 9.5 G — `9500 / 124` is 76.6, under two orders of magnitude. The
  rule as landed is satisfiable by *"three orders of magnitude"* beside a paste of 124 M:
  the reader is told to check, and given nothing to check with.
- **A constant of a pinned dependency quoted as a measurement.** #591's round-3 body
  quoted the never-hang floor as *"measured: 120 s"*; 120 s is
  `readinessPerAttemptFallback` in the pinned spec — not a sample, and not a dated
  reading — so arm **3f**'s premise (*a MEASURED FIGURE*) does not reach it at all.

This change adds the two lines the control was missing, each beside the text it extends,
in **one file**:

- `.agents/skills/git-workflow/references/pre-validator-self-audit.md` — the class-6
  **PROSE half** gains **the operands rule** (a relation is stated *with its operands*,
  so a reader can re-derive it by division from the pasted measurements, or it is
  dropped), and arm **3f** gains **the source rule** (a number that is not measured on a
  head is quoted *by its source* — the pinned spec's field, the manifest's key, the
  upstream's constant — and never as a measurement).

22 inserted lines, one file, no other path touched. The corpus is **GENERATED**: the
marketplace copy is not edited here. The corpus leg belongs to `opencharly/marketplace`,
and the projection of this committed tree into the corpus is shown below.

**The RCA — mechanism.** Both defects are claims whose *check* is real but whose *written
form* is not checkable by the reader: a relation without its operands, and a constant
wearing a measurement's clothes. They pass every check that asks *is this true* and fail
every check that asks *can the reader verify it from what is here*.

**The RCA — the missed control.** The class-6 arm was extended to the PROSE half by
#134 with a rule about **what to check**, and never with a rule about **what to write**.
A control that names only the truth condition is satisfiable by the exact defect it was
written for: the relation is "checked against the measurements" by the author, who holds
the numbers, and by no one else. The umbrella's own pre-push gate missed both for the
same reason — it asserted that the *evidence exists* and that the *command's exit code
matches the claim*, never that a reader could re-derive the claim from the paste.

**The RCA — blast radius.** Every PR in the org whose body carries a relation over its
own numbers, or a constant quoted as a measurement — that is, every PR that quantifies
its own change.

**The RCA — the root fix.** Two sentences in the file that owns the audit, beside the
text they extend. Both are additive to arms that already exist; neither duplicates 3b,
3c or 3f as they stand. The audited file is the only file changed.

```
$ cat /tmp/r1-repro/producer-sweep.sh
#!/usr/bin/env bash
# A claim-keyed sweep that sees a claim even when it spans a LINE BREAK.
#
# A line-oriented `git grep` reads one line at a time, so a claim whose words are
# split across a line break is invisible to it: the sweep is green while the
# claim sits in the file, which is a control in name only. This instrument folds
# each file's content to ONE line before the pattern is applied, so the pattern
# sees the file's text, not the file's line breaks.
#
# The file list is NUL-delimited (`find -print0` + `read -d ''`), so a path that
# contains a space is ONE path and not two — an unquoted `$(find .)` in a `for`
# loop splits it, and a sweep that walks a different file list than it claims to
# is a control in name only.
#
# usage: producer-sweep.sh <root> <pattern>
#   exit 0 = no match anywhere under <root>
#   exit 1 = at least one match (each is named)
set -u
root=${1:?usage: producer-sweep.sh <root> <pattern>}
pat=${2:?usage: producer-sweep.sh <root> <pattern>}
hits=0
while IFS= read -r -d '' f; do
  if tr '\n' ' ' <"$root/$f" | grep -qE "$pat"; then
    hits=$((hits + 1))
    echo "MATCH: ${f#./}"
  fi
done < <(cd "$root" && find . -type f -not -path './.git' -not -path './.git/*' -print0 | sort -z)
echo "hits=$hits"
[ "$hits" -eq 0 ]
```
