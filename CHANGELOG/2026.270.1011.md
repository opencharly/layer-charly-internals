# 2026.270.1011 — docs(internals): an issue resolved by a PR must be closed by an agent once that PR merges

## Summary

Adds to the `git-workflow` issue protocol: **an issue resolved by a PR must be closed by an
agent once that PR merges.**

- **B2b** — new paragraph "Close the issue when its PR merges": a PR that resolves an issue
  references it (`Closes #N` / `relates to #N`), and the author (or an agent) MUST ensure the
  issue is CLOSED once the resolving PR merges — never leave a resolved issue open. If the
  merge did not auto-close it, close it explicitly and comment the resolving PR/commit; an
  issue with no merged resolving PR is not resolved.
- **Invariant** — the "Search existing issues/PRs …" bullet now states the closing duty too.

`marketplace` corpus regeneration and the `docs` mirror.
