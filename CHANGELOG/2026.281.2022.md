## Summary

Four body-evidence bullets, all found in the field tonight, beside the eleven already merged (`#92`, `#93`, `#95`-`#102`).

**1. Locate an error OWNER in the module cache, not the checkout.** A message a program prints is emitted by whichever *module* built that code - rarely the repo the failing command was run in. `grep -rn <format string> $GOMODCACHE/<org>/` finds the file and line in one step. *Measured: three greps inside the repo that RAN the command found nothing; one grep across the module cache produced `loaderkit/walk.go:192`. An hour of guessing was an hour spent in the wrong repository.*

**2. A body claim must be one you RAN.** "I checked X and found none" is not evidence without the command and its output - **and pasting an empty result is a trap when the result is not empty.** *Measured: a sibling-absence claim whose grep matched twice, in an unrelated package.*

**3. A monitor alarm must have a CLEARING CONDITION, and its window must match the cadence of what it watches.** A state-shaped alarm fires at arm time while its condition holds, so on a permanently-silent item every re-arm re-fires immediately and the watch never actually waits. *An alarm whose condition cannot clear is not an alarm; it is a loop with a label.* **Where nothing can clear it, record the state instead of arming it** - and a window shorter than the item expected cadence manufactures the alarm it claims to detect.

**4. A monitor must be a MANAGED background command, and re-arming REPLACES rather than adds.** A detached watcher cannot be waited on, so the harness is never woken by it and every round becomes a poll. Arm one managed job over the whole list (a batched poll costs one request for N items), then block on it: *a completed job IS the wake.* **And the per-args lock does not save you: a changed item list is a different argument list, so re-arming with the new list starts a parallel watcher instead of replacing the live peer.** Stop the live watcher first, then arm one - `ps` is the authority, a job listing is not.
